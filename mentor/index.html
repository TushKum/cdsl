Free demo server: groups and accounts are wiped whenever it restarts or sleeps. Use it to try Pehla Kadam, not to run a real batch.
This page needs the Pehla Kadam server. Run it with npm start in the server folder and open this page from it, or add ?api=https://your-server to the address.

How it works

  1. Create a group for each batch you teach.
  2. Learners open the app, go to Profile → Cloud backup, turn on backup and enter the group code.
  3. Their progress appears here as they practise. You see names and progress only: never PINs, PAN or Aadhaar.
